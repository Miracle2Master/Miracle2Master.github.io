# 分区映射表：文件夹名 - 导航显示名
#
# 规则：
#   1) 每行一条，用「 - 」分隔（文件夹名 在前，导航显示名 在后）
#   2) # 开头是注释行，空行忽略
#   3) 行的先后 = 二级导航里的先后顺序
#   4) 新建 docs/<文件夹>/ 后，在这里加一行即可指定中文名；
#      不登记也能用，导航里会直接显示文件夹名，并排在所有已登记项之后
#   5) 登记了但 docs/ 下不存在的文件夹会被忽略，不会报错（方便先写后建）
#   6) 同一文件夹重复登记时以第一次出现为准
#   7) 文件夹名不能含「空格-空格」这种序列，否则会被当成分隔符
#
# 对应源码：.vitepress/config.mts 的 loadSectionMap() / buildSections()
