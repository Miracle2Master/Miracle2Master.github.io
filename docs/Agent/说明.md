# 关于这个分区

这里放的是 AI Agent 方向的知识梳理，目前以面试问答的形式组织：每个问题下都先给结论，再展开原理与工程细节，尽量做到能直接口述。

内容按主题分三块：

**RAG** —— 检索增强生成的完整链路。从文档切分、Embedding 选型、向量检索与关键词检索的差异，到多路召回、重排与评估指标，最后落到落地时最容易踩的坑。

**Agent** —— 从基本架构（LLM、工具、记忆、规划）出发，讲清 ReAct、Plan-and-Execute、Reflection 这几种推理范式的区别与选型，再延伸到 Multi-Agent 协作、记忆压缩、上下文工程、评测与线上 Trace 定位，最后几题讨论 Harness 设计与自进化这类更偏系统层面的问题。

**AI 面** —— 面试真题与口述回答稿，按实际面试顺序记录，偏个人经历的叙述方式。

## 阅读提醒

左侧目录按文件夹递归展开。每篇的题目都带编号，按顺序读是一条完整的知识线；也可以只挑某个关键词去搜，题目本身就是检索入口。

回答里会用第一人称讲项目中的做法，那是为了口述时顺口，不代表唯一的正确实现。
