# 关于这个分区

这里放的是 Java 后端与 Spring 生态的学习笔记，从基础框架一路铺到微服务架构。

内容大致分几类：

**框架与数据访问** —— Spring 的核心机制（IoC、AOP、Bean 生命周期）、MyBatis-Plus 的快速上手。

**中间件** —— Redis、消息队列、Elasticsearch，这几块占比最大。Redis 从基础命令一直到分布式缓存、多级缓存与原理篇。

**容器与部署** —— Docker 的环境准备、安装与快速入门。

**微服务** —— 服务拆分、网关路由、分布式事务、服务保护（限流、隔离、熔断）。

**AI 接入** —— Spring AI、Spring AI Alibaba、LangChain、RAG、AgentScope 这类把大模型接进后端应用的实践。

这些内容偏工程实践，多来自实际动手和踩坑记录，所以代码片段与配置示例比较多。阅读时如果看到某段配置和你的环境对不上，多半是版本差异。

## 阅读提醒

左侧目录按文件夹递归展开，可以逐级收起。标题里带编号的（如「一、Redis 概述」）是按讲解顺序写的，跳着看不影响理解，但连续读会更顺。
