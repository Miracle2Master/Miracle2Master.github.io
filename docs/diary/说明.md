# 关于这个日记分区

这里是日记与自我管理的归档区，记录的不是「发生了什么」，而是「怎么想、怎么判断、怎么改」。

内容大致分三类：

**日常记录** —— 按年月归档的日记正文，是原始素材。

**反思日记** —— 对过去的回看与复盘，比日记正文更凝练，重点在提炼出可复用的判断。

**体系文件** —— 原则、目标、评价这类不随时间流逝的顶层文本。它们不是记录，是判断标准和行动依据。

## 阅读提醒

这个分区是私密的，所以加了访问限制。点左侧任意标题会要求输入密码，验证通过后本次会话内不再重复询问。

左侧目录同样支持收起展开，标题行右侧有「全部展开 / 全部收起」。

## 关于这些内容的性质

日记里的判断有可能在后来被推翻。写下时的确信，不等于现在的结论，也不等于以后的结论。读旧内容时请把它当成「某个时点的思考」，而不是「既定事实」。

原则类文件会被反复修订——如果你看到两处说法不一致，以修改时间较新的那份为准。
